# mio-game-market

ミオのゲームアプリ販売所（MIO GAME MARKET）

AIといっしょに作ったスマホゲームや便利アプリ（ゲーム以外）を並べる、小さなお店のサイトです。

- `index.html` … お店のトップページ
- `games/nanatsu-no-akari-3d/` … 体験版「七つの灯 3D」

感想フォームをつなぐときは、`index.html` の `const FEEDBACK_URL='';` にフォームのURLを入れます。
- MAMORU（健康管理アプリ）… https://mamoru-health.floot.app へのリンクで掲載
